# 2025-11-17 VM マウント構成メモ

## 背景
- macFUSE を避けつつ `lit on` 相当の体験を得るため、Linux VM 側で lit-fs を起動し、ホストからはネットワーク共有でアクセスする構成を検討。
- Windows/ macOS 共通で適用できるよう、まず Mac + Vagrant(Ubuntu 24.04) での手順を整備。

## 実装概要
- `lit on/off --vm-config <json>` / `LIT_VM_CONFIG` を追加。FUSE を使えない場合は VM 設定を読み込み、VM 上で `lit on/off`・NFS export を実行しつつ、ホスト側では `sudo mount/umount` する。状態は `~/.lit/workspaces/<id>/vm.json` に保存され、`lit off` は `--vm-config` なしでも vm.json を参照してクリーンアップする。
- `scripts/lit-vm-mount.sh`: SSH 経由でVM上に lit ワークスペースを作成し、NFS エクスポートを設定。ホスト側では `sudo mount -t nfs` で `./tmp/vm-workspace` にマウント。
- `doc/vm-mount.md`: アーキテクチャ、サンプルコマンド、Windows への展開方針、`--vm-config` サンプルJSONを記載。
- README の注意事項に VM 経由運用を追記。

## 使い方 (Mac例)
1. `lit on ./tmp/vm-workspace --vm-config ~/.lit/vm-config.json` または `./scripts/lit-vm-mount.sh prepare` → VM 側で lit on と NFS export を実行。
2. `sudo ./scripts/lit-vm-mount.sh mount` もしくは CLI による自動 `sudo mount -t nfs ...` で `./tmp/vm-workspace` を利用。
3. 作業後 `lit off ./tmp/vm-workspace`（vm.jsonがあるため自動でVM側も片付け）または `./scripts/lit-vm-mount.sh umount` → `stop` でクリーンアップ。

## 留意点
- VM側に `nfs-kernel-server` が必要。`prepare` が `apt-get` まで自動実行。
- NFS は `anonuid`/`anongid` を lit 実行ユーザーに固定しているため、chmod/chown を行う際はVM側ユーザー権限で実施すること。
- Windows では NFS クライアント機能を有効化するか、今後 Samba 例を追加予定。
- 2025-11-17: state-based CRDT 仕様への移行に合わせ、`doc/spec.md` を更新し `lit sync --workspace` が snapshot (CvRDT) を export/import できるようにする実装を開始。`lit-cli/src/state_sync.rs` で `WorkspaceSnapshot` を定義し、`run_sync` がローカル snapshot を生成して保存するようになった。
